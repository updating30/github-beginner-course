# GitHub 実務講座（全5回）— 50代ビジネスパーソンのための「ファイル管理革命」

「企画書_最新_修正版_本当に最終.xlsx」のようなファイルに困っている、IT初心者のビジネスパーソン向けの講座です。黒い画面（コマンド）はほとんど使わず、GitHub Desktop と VS Code の画面操作で、変更の記録・試作・共有までを身につけます。

**講座ページ（ブラウザで開けます）**：https://updating30.github.io/github-beginner-course/

## 講座の流れ

| 回 | タイトル | 主なツール | キーワード |
| --- | --- | --- | --- |
| 第1回 | GitHubって何？タイムマシンを手に入れよう | GitHub Desktop | リポジトリ・コミット |
| 第2回 | 安全に試作する「実験ルーム」を作ろう | GitHub Desktop | ブランチ |
| 第3回 | チームに共有・上司に確認を求める | GitHub.com | プルリクエスト |
| 第4回 | PythonコードをGitHubで管理する | VS Code + GitHub | 実務への応用 |
| 第5回 | AIと一緒にコードを書く現代の開発スタイル | VS Code + Copilot | GitHub Copilot |

## 工夫したこと

- **仕事の言葉で例える**：リポジトリは「プロジェクト金庫」、コミットは「変更履歴の台帳」、プルリクエストは「デジタル上の稟議」
- **手順は画面操作で**：各回に「学習のゴール」「例え話」「具体的な操作手順」「得られるメリット」をそろえた
- **続けたくなる仕掛け**：講座ページに、レベル・経験値（XP）・実績のしくみを入れた（進み具合はブラウザの中にだけ保存）
